# Import Rehearsal Fixtures

These fixture profiles define the import rehearsal coverage expected before write-capable imports mature.

| Fixture | Purpose |
| --- | --- |
| Small wiki | Minimal personal wiki with a homepage, one category, one tag, and one asset. |
| Large archive | Large archive with many articles, revisions, assets, and tag merges. |
| Docs portal | Versioned docs categories, redirects, and public/private page filters. |
| Worldbuilding atlas | Maps, characters, locations, revisions, and custom metadata. |

Fixtures are contract profiles in v4.81.2, not executable imports.
