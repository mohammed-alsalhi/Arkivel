# Example Theme Pack

This sample shows the folder shape for a marketplace theme contribution. Replace the placeholder values with your pack metadata, local screenshots, compatibility notes, and test evidence before submission.

## Contents

- `manifest.json` declares preview metadata for a theme pack.
- `screenshots/README.md` describes required preview images.
- `tests/README.md` lists validation, accessibility, and responsive checks.

## Review notes

- Keep the theme scoped to supported color and font CSS variables.
- Do not include executable payloads, install scripts, remote code, or file-write behavior.
- Validate the manifest with `/admin/marketplace` import preview.
